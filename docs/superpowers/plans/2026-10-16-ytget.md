# YTGet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build private Android-only Flutter app that converts YouTube to MP3/MP4 on-phone via bundled yt-dlp and sideloads via APK.

**Architecture:** Single Flutter app, no backend. UI -> DownloaderService -> yt-dlp/ffmpeg processes -> MediaStore Download/YTGet. Binaries bundled per-ABI, updated in-app.

**Tech Stack:** Flutter 3.47.2 / Dart 3.13.2, yt-dlp android binary (arm64), ffmpeg_kit_flutter, receive_sharing_intent, permission_handler, open_filex, share_plus, cached_network_image, path_provider, sqlite via drift or shared_prefs v1 history

## Global Constraints

- Android only, sideload APK, no Play Store upload.
- On-phone only, no servers, no API keys, no analytics.
- yt-dlp required for full-length (pure-Dart truncates to ~60s as of Aug 2026 PO Token).
- Save to Download/YTGet via MediaStore on Android 10+.
- Personal use only disclaimer in app + README.
- `flutter build apk --split-per-abi` must succeed.

```dart
// lib/core/youtube_url.dart
class YoutubeUrl {
  final String videoId;
  YoutubeUrl(this.videoId);
  static final _idRe = RegExp(r'^[A-Za-z0-9_-]{6,12}$|^[A-Za-z0-9_-]{11}$');
  static YoutubeUrl parse(String raw) {
    final u = Uri.tryParse(raw.trim());
    if (u == null || u.host.isEmpty) throw ArgumentError('Invalid URL');
    if (u.host.contains('youtu.be')) {
      final id = u.pathSegments.isNotEmpty ? u.pathSegments.first : '';
      if (_idRe.hasMatch(id)) return YoutubeUrl(id);
    }
    if (u.host.contains('youtube.com') || u.host.contains('music.youtube.com')) {
      final v = u.queryParameters['v'];
      if (v != null && _idRe.hasMatch(v)) return YoutubeUrl(v);
      if (u.pathSegments.length >= 2 && (u.pathSegments[0] == 'shorts' || u.pathSegments[0] == 'embed' || u.pathSegments[0] == 'live')) {
        final id = u.pathSegments[1];
        if (_idRe.hasMatch(id)) return YoutubeUrl(id);
      }
    }
    throw ArgumentError('Unsupported YouTube URL');
  }
  static bool isSupportedUrl(String raw) {
    try { parse(raw); return true; } catch (_) { return false; }
  }
}
```

```dart
// lib/core/download_args.dart
List<String> buildMp3Args(String url, int kbps, String outTpl) =>
  ['-x','--audio-format','mp3','--audio-quality','${kbps}K','--no-playlist','--newline','--progress','-o',outTpl,url];
List<String> buildMp4Args(String url, int maxH, String outTpl) =>
  ['-f','bv*[height<=$maxH]+ba/b/best','--merge-output-format','mp4','--no-playlist','--newline','--progress','-o',outTpl,url];
List<String> buildInfoArgs(String url) =>
  ['--dump-json','--no-playlist','--skip-download',url];
// lib/core/progress_parser.dart
double? parseProgressLine(String line) {
  final m = RegExp(r'(\d+(?:\.\d+)?)%').firstMatch(line);
  if (m == null || !line.contains('[download]')) return null;
  return double.parse(m.group(1)!) / 100.0;
}
```

- [ ] **Step 4: ytdlp_service.dart (process wrapper, no test — manual)**

```dart
import 'dart:async'; import 'dart:convert'; import 'dart:io';
import 'download_args.dart';
class VideoMeta { final String title, author, thumb; final int durSec; VideoMeta(this.title,this.author,this.thumb,this.durSec); }
class YtDlp {
  final String binPath;
  YtDlp(this.binPath);
  Future<VideoMeta> fetchInfo(String url) async {
    final r = await Process.run(binPath, buildInfoArgs(url));
    if (r.exitCode != 0) throw Exception(r.stderr.toString().split('\n').first);
    final j = jsonDecode((r.stdout as String).split('\n').firstWhere((l)=>l.trim().startsWith('{'))) as Map;
    return VideoMeta(j['title']??'Unknown', j['uploader']??'', j['thumbnail']??'', (j['duration']??0) as int);
  }
  Stream<double> download(List<String> args, {void Function(String)? onLog}) {
    final c = StreamController<double>();
    Process.start(binPath, args).then((p) {
      p.stdout.transform(const SystemEncoding().decoder).transform(const LineSplitter()).listen((l){ onLog?.call(l); final v = parseProgressLine(l); if (v!=null) c.add(v); });
      p.stderr.transform(const SystemEncoding().decoder).transform(const LineSplitter()).listen((l)=>onLog?.call(l));
      p.exitCode.then((e){ e==0 ? c.close() : c.addError('yt-dlp exit $e'); });
    });
    return c.stream;
  }
}
```
